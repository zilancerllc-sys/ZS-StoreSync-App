## Bugs found and fixed

1. Undo could not delete a location: Admin API 2026-10 requires `@idempotent` on
   `locationDeactivate` ("The @idempotent directive is required…"). Fixed in `app/undo.server.js`;
   verified live (location removed by Undo).
2. Shipping re-runs duplicated custom profiles: the target's profile list used
   `merchantOwnedOnly: true`, which hides profiles created by an app, and a profile ZS StoreSync
   created is app-owned. Target side now lists all profiles (`app/migrator-more.server.js`).
3. Undo confirm read "Delete 1 items" / "the 1 items": singular copy added (`app/components/UndoRunButton.jsx`)
   with translations in all 6 locales.
